# Loan-Approval-Prediction-System

## 📌 Project Overview

This project uses Machine Learning techniques to automate the loan approval process. The model analyzes applicant details such as income, credit score, loan amount, employment status, and other financial factors to predict loan approval.

The project covers the complete machine learning workflow including data preprocessing, feature engineering, model training, evaluation, and prediction.

---

## 🎯 Objectives

- Predict loan approval using applicant information.
- Compare different Machine Learning algorithms.
- Select the best-performing model based on evaluation metrics.
- Predict the loan status for new applicants.

---

## 📂 Dataset Features

The dataset contains the following information:

- Applicant Income
- Coapplicant Income
- Employment Status
- Age
- Marital Status
- Dependents
- Credit Score
- Existing Loans
- Savings
- Debt-to-Income Ratio (DTI)
- Loan Amount
- Loan Term
- Property Area
- Education Level
- Employer Category
- Loan Purpose
- Collateral Value

**Target Variable**

- Loan_Approved

## ⚙️ Machine Learning Workflow

### Data Preprocessing

- Loaded the dataset
- Handled missing values
- One-Hot Encoding for categorical variables
- Feature Scaling using StandardScaler
- Train-Test Split

### Machine Learning Models

- Logistic Regression
- K-Nearest Neighbors (KNN)

### Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
